Plugins for Logic Pro

All 16 of our plugins are Audio Units, so they load straight into Logic Pro. Every Mac installer is notarised by Apple, so it opens without a security warning.

Run the installer and restart Logic Pro. Our plugins appear in the Audio Units menu under Plugins for Breakfast. If one is missing, open Settings, Plug-in Manager, and choose Reset & Rescan.

The same installer also puts in VST3 and AAX, so the plugins are ready if you open the project in another DAW later.

Questions

How do I install AU plugins in Logic Pro?

Run the installer and restart Logic Pro. If a plugin does not show up, go to Settings, Plug-in Manager and choose Reset & Rescan.

Do they run on Apple silicon?

Yes. They run on Apple silicon and Intel Macs, on macOS 11 or later.

Can I try them before buying?

Yes. Every plugin has a 3-day free trial, and Butter Spread, our stereo widener, comes with a free licence.
